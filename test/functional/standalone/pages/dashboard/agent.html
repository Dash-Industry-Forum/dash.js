How It Works

This page keeps the device registered and available for remote test dispatch. Leave it open on your target device (Smart TV, set-top box, game console, etc.).

  1. This page connects to the server and registers the device
  2. A heartbeat is sent every 30 seconds to keep the device online
  3. When you dispatch a test run from the Dashboard, this device receives the configuration and automatically navigates to the test runner

Tip: On Smart TVs, you can add this page to the TV’s browser bookmarks for quick access.
