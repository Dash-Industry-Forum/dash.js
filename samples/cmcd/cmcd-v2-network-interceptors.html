CMCD v2 Callbacks with Network Interceptors

This sample shows how to use Network Interceptors to execute callbacks after server response or pre-request callbacks for Response and Event Mode. The predefined CMCD event target is disabled by default so the sample can be used without a local collector. Enable it only when you want to test against a running endpoint.

Default endpoint: http://localhost:3333/cmcd/response-received
