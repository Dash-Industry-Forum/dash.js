CMCD v2 Reporting

This sample shows how to use dash.js in order to enhance requests to the CDN with Common Media Client Data (CMCD - CTA 5004). Please note that in this sample we are also enabling the CMCD v2 event mode next to the common request mode. To fully demonstrate the event mode, there needs to be a server that collects the metrics that are sent out when an event is triggered. We provide a local dummy server for this purpose which can be found in `samples/simple-express-server`.
