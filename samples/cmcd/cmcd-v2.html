CMCD v2 Reporting

This sample shows how to use dash.js in order to enhance requests to the CDN with Common Media Client Data (CMCD - CTA 5004). Please note that in this sample we are also enabling the CMCD v2 event mode next to the common request mode. The predefined event targets are disabled by default so the sample can be used without a local collector. To demonstrate the event mode, enable the targets you want to test and point them to a running collector such as the local dummy server in "samples/simple-express-server".

Predefined CMCD v2 Event Targets

Enable only the targets you want to use. Each target keeps the current sample endpoint as its default, but starts disabled to avoid failed localhost requests.
