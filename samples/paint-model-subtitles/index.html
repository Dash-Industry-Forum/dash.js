Payload bytes on the wire, same segment, all four tracks

TrackSegmentCMAF bytesCMAF kbit/s LOCMAF bytesLOCMAF kbit/sSamples

Bytes are the segment as served, without HTTP: for CMAF the styp and every chunk's moof and mdat header; for LOCMAF the same chunks encoded as LOCMAF Objects, one MoQ group per segment, without MoQ Object headers. The LOCMAF figures come from the Eyevinn/locmaf reference encoder, run in this page as WebAssembly (loading). This page fetches and walks each segment of the selected track once the player has completed it, and the same segment number of the other three tracks every fifth segment, to keep the request count low. kbit/s is the average over the last 10 segments fetched per track.
