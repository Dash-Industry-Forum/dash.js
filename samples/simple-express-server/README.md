# simple-express-server

This sample is a minimal Express server used by dash.js samples.

## Prerequisites

- Node.js (npm included)

## Build

There is no compile/build step in this sample. Install dependencies:

```bash
npm install
```

## Start

Run the server:

```bash
npm start
```

The `start` script runs `node ./bin/www`.

By default, Express generator apps usually listen on port `3333` unless `process.env.PORT` is set.

## Optional: custom port

```bash
PORT=8080 npm start
```
