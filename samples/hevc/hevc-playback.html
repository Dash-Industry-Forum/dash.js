Play HEVC streams in dash.js — software fallback for any browser

HEVC (H.265) playback depends on the browser exposing an HEVC decoder. Several common configurations cannot — Windows Chrome without a HEVC-capable GPU, Windows Edge / Firefox without the Microsoft HEVC Video Extension, and Linux Chrome / Firefox.

@hevcjs/dashjs-plugin fills that gap: HEVC samples are transcoded to H.264 in a Web Worker (WASM decoder + WebCodecs encoder) and dash.js keeps playing a standard H.264 stream. No-op when HEVC is supported natively (macOS, iOS, capable Windows configs).
